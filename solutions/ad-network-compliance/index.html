Fail-Open Architecture

Because we process traffic at the edge across 38 global PoPs, scoring occurs near the user. If an edge node ever experiences a timeout, the request is passed through seamlessly—meaning a slow system moment will never cost you a legitimate click.

Stateless Request Forwarding

Your tracker stays your system of record. CloakShield logs the security metrics, appends the results as request headers (x-cs-score, x-cs-geo), and hands the click over with sub-parameters fully intact.
